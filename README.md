## What’s new in this update

[![Tablet experience](https://img.shields.io/badge/TABLET%20EXPERIENCE-EASIER%20TO%20USE-DB2777?style=for-the-badge)](#a-more-comfortable-tablet-experience)

### A more comfortable tablet experience

COCCE now makes better use of a tablet’s larger screen. Feed controls are easier to use, Shop shortcuts are balanced across the screen, and the Welcome screen feels more at home on a tablet.

All existing app features and all 24 app languages remain included.
