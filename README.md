## What’s new in 1.0.28

### Shared links

[![Shared links](https://img.shields.io/badge/SHARED%20LINKS-EASIER%20TO%20OPEN-DB2777?style=for-the-badge)](#shared-links)

**Shared links open more easily.** Links in shared messages are easier to tap, including addresses written without `https://`.

### Refreshes

[![Refreshes](https://img.shields.io/badge/REFRESHES-KEEP%20YOUR%20PLACE-0284C7?style=for-the-badge)](#refreshes)

**Keep your place while things refresh.** Your Ads, messages and notifications stay on screen while they update, with a clear progress cue instead of replacing the content you were viewing.

### COCCE TV

[![COCCE TV](https://img.shields.io/badge/COCCE%20TV-CLEAR%20SCHEDULING%20PROGRESS-EA580C?style=for-the-badge)](#cocce-tv)

**See when COCCE TV scheduling is working.** TV admins get a clear progress message while they add the next program, and can keep the current program list in view.

All existing app features and all 24 app languages remain included.
